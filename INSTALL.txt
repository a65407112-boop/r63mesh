R63 MESH GUI v1.2 — установка

Выполни:
loadstring(game:HttpGet("https://raw.githubusercontent.com/a65407112-boop/r63mesh/main/local_character_meshes.lua?v=1.2.0"))()

GUI откроется, а пять файлов RBLXBikiniMod с GitHub автоматически появятся
в LocalCharacterMeshes/Packs/RBLXBikiniMod. Это R6-набор: для R15 нужны
отдельные меши R15. Скрипт не меняет тип рига игры.
Существующие файлы не заменяются; кнопка GitHub добавляет недостающие.

СВОЙ НАБОР
1. В workspace executor создай LocalCharacterMeshes/Packs/ЛюбоеНазвание.
2. Положи туда нативные .mesh с именами частей тела: Torso.mesh, LeftArm.mesh
   и т.д. для R6 либо UpperTorso.mesh, LeftUpperArm.mesh и т.д. для R15.
   Можно использовать подпапки R6 и R15 внутри набора.
3. Открой селектор наборов в GUI или обнови список.
4. Выбери папку и нажми Применить. Выбор сохранится для респавна.
Это папки executor на диске, не объект Workspace внутри Roblox.

GUI также принимает ID/ссылку предмета каталога или набора, показывает
выбранные ID и позволяет удалять их. Меши можно отключить отдельной кнопкой.
RightShift скрывает/показывает окно. После сворачивания нажми R63.
Перетаскивай заголовок мышью или касанием. Stop восстанавливает исходный аватар.

В новом сервере скрипт нужно выполнить снова.
Старые LocalCharacterMeshes/R6 и /R15 доступны как «Мои меши (R6 / R15)».
При ручной установке скачанного репозитория сохрани свои config.json,
avatar_items.json и selected_pack.txt перед копированием.

Мешам нужны совместимые Roblox UV для рубашек/штанов и cages для объёмной
одежды. Скрипт не исправляет UV и не создаёт кости/cages. Доступные предметы
можно примерять локально; закрытые, удалённые, несовместимые и неподдерживаемые
ID могут отклоняться. Предметы не покупаются, аватар аккаунта не меняется.
Другие игроки и NPC сохраняют свои меши, окружающие видят обычный аватар.

Нужны filesystem + getcustomasset с поддержкой .mesh, HTTP и API Roblox.
Для безопасного отката установки готового набора требуется delfile.
Проверены синтаксис Lua и 43 сценария в симуляции; живой запуск в Roblox,
отрисовка одежды и совместимость executor здесь не проверялись.

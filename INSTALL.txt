LOCAL CHARACTER MESHES v1.1 — установка

1. Распакуй содержимое этого ZIP прямо в workspace своего executor.
   Должны получиться:
   workspace/local_character_meshes.lua
   workspace/LocalCharacterMeshes/R6/Torso.mesh
   workspace/LocalCharacterMeshes/R6/LeftArm.mesh ...
   Это папка executor на диске, не объект Workspace внутри Roblox.
   Если папка уже существует, сначала сохрани свои config.json/avatar_items.json:
   не заменяй их пустыми файлами из этого пакета, если хочешь оставить настройки.
2. Открой local_character_meshes.lua в executor и выполни его на клиенте.
   Либо используй loadfile("local_character_meshes.lua")(), если есть loadfile.
3. Для обновления файлов снова выполни скрипт или вызови:
   getgenv().LocalCharacterMeshes.Reload()

Предмет по ASSET ID:
   getgenv().LocalCharacterMeshes.Wear(123456789)
Набор по BUNDLE ID:
   getgenv().LocalCharacterMeshes.WearBundle(12345)
Убрать один предмет / набор:
   getgenv().LocalCharacterMeshes.Remove(123456789)
   getgenv().LocalCharacterMeshes.RemoveBundle(12345)
Убрать все запрошенные ID, оставив свои меши:
   getgenv().LocalCharacterMeshes.ClearItems()
Восстановить исходный внешний вид:
   getgenv().LocalCharacterMeshes.Stop()

Вместо примеров 123456789/12345 поставь настоящие ID из каталога.
Wear принимает ID предмета каталога, а не ID его внутренней текстуры/mesh.
Список сохраняется в avatar_items.json и применяется при респавне.

Включены все пять .mesh из присланного RBLXBikiniMod (Open Me).zip.
Их байты и UV-развёртки сохранены без изменений. Переименованы только файлы.
Набор предназначен для R6. На R15 эти пять файлов не применяются: нужны
отдельные R15 меши в папке R15. Скрипт не меняет тип рига игры.

Изменения видны только тебе и относятся к твоему персонажу. Другие игроки
и NPC сохраняют свои меши. Это не покупает предметы и не меняет аккаунт.
Поддерживаются доступные Roblox аксессуары, классическая/объёмная одежда,
лица и части тела, совместимые с текущим ригом. Закрытые/удалённые предметы,
неподдерживаемые типы и несовместимые ID могут быть отклонены.
Нельзя обещать буквально ЛЮБОЙ ID. Анимации, модели, инструменты, сырые
меши/декали и новые неподдерживаемые категории не являются Wear-предметами.

Одежда использует существующую Roblox UV-развёртку меша. Наличие любых UV
не гарантирует соответствия шаблону Roblox. Развёртка присланного набора
структурно прочитана, но её соответствие рубашкам/штанам не проверено
в Roblox. Скрипт не генерирует UV, кости или клетки для объёмной одежды.

В режиме ID создаётся локальная визуальная модель с исходными данными
аватара Roblox. Она следует за позой твоего персонажа, не участвует
в столкновениях, а настоящий персонаж сохраняет управление и камеру.
Своим мешам отдаётся приоритет над геометрией предметов по ID.
В режиме только .mesh R15 ApplyMesh меняет и локальную геометрию столкновений.
Нестандартные риги, лицевые анимации и эффекты конкретных игр не гарантируются.

Нужны файловые функции executor и getcustomasset с поддержкой .mesh.
Проверены синтаксис Lua и 26 сценариев в симуляции. Запуск в Roblox,
отрисовка одежды и совместимость с твоим executor здесь не проверялись.
Подробности: LocalCharacterMeshes/README.txt и AVATAR_ITEMS.txt.

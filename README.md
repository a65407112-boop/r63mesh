# Local Character Meshes

Локальный загрузчик собственных мешей персонажа Roblox и предметов аватара по ID.
Изменения видны только на твоём клиенте. Другие персонажи сохраняют свои меши.

## Установка

1. Скопируй `local_character_meshes.lua` и папку `LocalCharacterMeshes` в workspace своего executor.
2. Открой скрипт в executor и выполни его на клиенте Roblox.
3. Чтобы перечитать изменённые файлы, выполни скрипт снова или вызови `Reload()`.

В `LocalCharacterMeshes/R6` включены пять мешей из присланного `RBLXBikiniMod (Open Me).zip`:
торс, обе руки и обе ноги. Байты файлов сохранены без изменений. Это набор для R6.
Для R15 нужны отдельные меши с именами частей R15; скрипт не меняет тип рига игры.

Если у тебя уже есть настройки, сохрани свои `config.json` и `avatar_items.json`
перед копированием папки из репозитория.

## Команды

```lua
local avatar = getgenv().LocalCharacterMeshes
avatar.Wear(123456789)    -- замени на ID предмета каталога
avatar.WearBundle(12345) -- замени на ID набора каталога
avatar.Remove(123456789)
avatar.RemoveBundle(12345)
avatar.ClearItems()      -- убрать запрошенные ID, оставить собственные меши
avatar.Reload()
avatar.Stop()            -- восстановить исходный внешний вид
```

Список ID сохраняется в `LocalCharacterMeshes/avatar_items.json` для респавна.
Предметы по ID собираются штатным механизмом Roblox в локальную визуальную модель,
которая следует за позой настоящего персонажа. Управление и камера остаются у
настоящего персонажа. Собственные меши заменяют соответствующую геометрию визуальной модели.

## Требования и ограничения

- Executor должен предоставлять файловые функции и `getcustomasset` с поддержкой `.mesh`.
- Принимаются нативные Roblox `.mesh`; переименование OBJ/FBX не конвертирует их.
- Поддерживаются доступные и совместимые классические вещи, аксессуары, объёмная одежда,
  лица и части тела. Недоступные, удалённые, несовместимые и неподдерживаемые ID могут быть отклонены.
- `Wear()` принимает ID предмета каталога, а не ID его внутреннего mesh или текстуры.
- Одежде нужна совместимая Roblox UV-развёртка. Скрипт не создаёт и не исправляет UV,
  клетки объёмной одежды или кости. UV присланного набора сохранены; соответствие одежде
  ещё не проверено в Roblox.
- Нестандартные риги, лицевые анимации и эффекты конкретных игр не гарантируются.
- Это локальный просмотр; он не покупает предметы и не меняет аватар аккаунта.

## Проверка

Для скрипта проверены синтаксис Lua и 26 сценариев в симуляции. Реальный запуск в Roblox,
отрисовка одежды и совместимость с конкретным executor здесь не проверялись.

Скрипт подготовлен в этом проекте. Включённые меши предоставлены пользователем;
дополнительная лицензия на чужие меши этим репозиторием не назначается.

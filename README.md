# R63 Mesh GUI

Локальные меши и предметы аватара Roblox с GUI и селектором папок.
Изменяется только внешний вид твоего персонажа на твоём клиенте.

## Запуск

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/a65407112-boop/r63mesh/main/local_character_meshes.lua?v=1.2.0"))()
```

Скрипт создаёт папки в workspace executor, открывает GUI и скачивает недостающие
файлы готового набора `RBLXBikiniMod` из этого GitHub. В нём пять оригинальных
мешей из присланного ZIP: торс, обе руки и обе ноги. Их байты сохранены.
Набор рассчитан на **R6**; скрипт сохраняет тип рига текущей игры.
На свежем R6 он выбирается автоматически. Существующие меши и настройки сохраняются.

## Свои папки в селекторе

1. Создай `LocalCharacterMeshes/Packs/ЛюбоеНазвание` в workspace executor.
2. Положи туда `.mesh` с именами частей тела, например `Torso.mesh` для R6
   или `UpperTorso.mesh` для R15. Поддерживаются пробелы и Unicode в имени папки.
3. Открой селектор наборов в GUI или нажми обновление списка.
4. Выбери свою папку и нажми **Применить**.

Можно разделить один набор на подпапки `R6` и `R15`. Если подпапка текущего рига
есть, меши берутся из неё; иначе — из корня набора. Выбор сохраняется в
`selected_pack.txt` и возвращается после респавна. Для нового сервера запусти скрипт снова.

Старые папки `LocalCharacterMeshes/R6` и `/R15` доступны через
«Мои меши (R6 / R15)». Кнопка **GitHub** устанавливает недостающие файлы готового
набора, сохраняя пользовательские файлы. Полный список имён: [PACKS.txt](LocalCharacterMeshes/PACKS.txt).

## GUI

- Надевание по ID предмета или ID каталожного набора; принимаются соответствующие ссылки Roblox.
- Список выбранных ID, удаление одного или всех.
- Селектор папок, применение, обновление, отключение собственных мешей.
- Сворачивание и кнопка R63 для открытия; RightShift скрывает/показывает окно.
- Перетаскивание за заголовок мышью или касанием; размер подстраивается под экран.
- Stop восстанавливает исходный внешний вид и закрывает загрузчик.

## Команды и настройки

```lua
local avatar = getgenv().LocalCharacterMeshes
avatar.ListPacks()
avatar.SelectPack("ЛюбоеНазвание")
avatar.SelectPack("") -- исходные папки R6/R15
avatar.InstallPack() -- загрузить RBLXBikiniMod из GitHub
avatar.SetMeshesEnabled(false)
avatar.ShowUI()
avatar.Wear(123456789) -- ID предмета каталога
avatar.WearBundle(12345) -- ID набора каталога
avatar.Remove(123456789)
avatar.RemoveBundle(12345)
avatar.ClearItems()
avatar.Reload()
avatar.Stop()
```

Необязательный `config.json` в папке набора использует разделы `R6`/`R15`, как
[основной config.json](LocalCharacterMeshes/config.json). Имена файлов в нём
относятся к выбранной подпапке рига или корню набора. Описание параметров
текстуры, масштаба головы и cages: [README.txt](LocalCharacterMeshes/README.txt).
ID сохраняются в `avatar_items.json` после успешной загрузки.

Для запуска без GUI или автозагрузки перед loadstring можно установить
`getgenv().LocalCharacterMeshesGUI = false` либо
`getgenv().LocalCharacterMeshesAutoInstall = false`.

## Совместимость

Нужны файловые функции executor, HTTP, `getcustomasset` с поддержкой `.mesh`
и текущие API Roblox. Для установки готового набора нужен `delfile`, чтобы
откатывать незавершённую запись. Переименование OBJ/FBX в `.mesh` не конвертирует файл.

Одежде нужна совместимая **Roblox UV-развёртка**; объёмной одежде также нужны
подходящие cages и данные аватара. Скрипт сохраняет существующие данные, но
не создаёт UV, cages или кости. Отображение одежды на присланном наборе требует проверки в Roblox.

Поддерживаются доступные, совместимые предметы аватара: аксессуары,
классическая/объёмная одежда, лица и части тела. Удалённые, закрытые,
неподдерживаемые и несовместимые ID могут отклоняться; буквально «любой ID»
обещать нельзя. ID предмета каталога и внутренний mesh/texture ID различаются.

Предметы по ID собираются штатным механизмом Roblox в локальную визуальную
модель, следующую за позой настоящего персонажа. Она не участвует в столкновениях;
настоящий персонаж сохраняет управление и камеру. Собственные меши имеют
приоритет над геометрией предметов. В режиме только мешей R15 ApplyMesh
меняет и локальную геометрию столкновений.

Проверены синтаксис Lua и **43 сценария в симуляции**, включая селектор, респавн,
отмену загрузки и откат настроек. Живой запуск, отрисовка и конкретный executor
здесь не проверялись. Дополнительные инструкции: [INSTALL.txt](INSTALL.txt),
[AVATAR_ITEMS.txt](LocalCharacterMeshes/AVATAR_ITEMS.txt).

Включённые меши предоставлены пользователем. Дополнительная лицензия на чужие
меши этим репозиторием не назначается.
